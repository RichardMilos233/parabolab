## 1. 论文主张（一句话）

对固定的 coding-tree 展开，**什么时候能用蒙特卡洛算，由"绝对值优势方程"（majorant
system）的爆炸时间唯一决定**，与时钟、分支概率等采样选择无关；在这个时间之内，总能构造出
**输出有确定上界、无偏、期望工作量有限**的采样器。常用的固定速率采样器在严格更早的时刻就会
失去有限方差，因此过去文献中的"短时间限制"大部分是采样器造成的，不是表示本身的限制。

与已有文献的差别（已核对）：
- Huang–Privault, *Stability analysis of a branching diffusion solver…*
  ([arXiv:2502.17853 v2](https://arxiv.org/abs/2502.17853), 2026-03) 与
  *Probabilistic representation of ODE solutions with quantitative estimates*
  ([arXiv:2502.10644](https://arxiv.org/abs/2502.10644), JMAA 2026)：
  两篇都**只给充分条件**，后者自述只给出爆炸时间的"隐式下界"。两篇都没有必要条件、没有精确
  时间，也没有讨论采样选择能否改变可积性。
- HLOTTW 2019 (AIHP)、Agarwal–Claisse 2020 (SPA)、NPP 2023 (JEQ)：都假设可积性，
  或只在"短时间 / 小非线性"下成立。
- 分支粒子与 Fujita 型爆破的联系是经典结果（López-Mimbela–Wakolbinger；
  Chakraborty–López-Mimbela 2008；Escobedo–Levine 1995）。定理 E 是把这些方法用到
  coding-tree 的矩系统上，**不声称方法新**。
- 零方差重要性抽样、Doob h-变换、Boltzmann sampler 都是经典工具。定理 B 的新意在于：在
  带导数 code 的 coding tree 上把它们做成**可顺序实现**的采样器，并由此得到**精确**的
  "所有采样器可达时间的上确界"。

## 3. 缺口与任务（按顺序）

- **G1 一般 tilted 采样定理**：针对半线性机制
  M(g*)={(f*,(g')*),(∂,∂,−½(g'')*)}，M(∂)={((f')*,∂)}，在 d 维环面和 R^d 上写出
  顺序采样律（叶子 / 分支时间 / 位置 / tuple 的条件密度都由 Ŵ 决定），并证明无偏性和
  \|H\|≤Ŵ_Id。需要处理的细节：Ŵ 只在几乎处处有限；分支的全部子节点共享同一位置（gotcha 1）；
  killing 质量等于上解的亏量。
- **G2 工作量判据**：θ-系统的有限性 ⇒ E[N]<∞；在常数数据和 sup-majorant 常数上解
  两种情况下给出显式界。
- **G3 实现**：在 `parabolab/` 中加一个 sup-majorant tilted 采样器（常数上解 ⇒ 只需解
  一个 ODE），兼容 `Solver.solve(pde, grid) -> Curve`；测试：均值对上精确解，
  \|H\|≤界逐样本成立。
- **G4 数值**：
  (i) 平坦 Allen–Cahn，T 取 0.5、0.9、1.2、1.4（超过所有固定速率采样器的 L2 极限 <1），
      报告 Hoeffding 置信区间；
  (ii) 非恒定行波：比较固定速率采样器与 sup-tilt 采样器的可用时间、方差和节点数，
      失败的对比也如实报告；
  (iii) JCP Table 5 那类重尾偏差：有界输出 ⇒ 非渐近置信区间，这是固定速率采样器给不了的。
- **G5 手稿**：LaTeX，`docs/research/paper/manuscript/`。结构：引言 → 框架与合同 →
  A/B/B' → C → D/E → F（固定采样器的差距）→ 数值 → 讨论。
- **G6 文献节**：逐条对照 HLTT14、HLOTTW19、AC20、NPP23、HP25/26、PP22 (Butcher)、
  LMW、CLM08、EL95、Kahn–Marshall/Booth（零方差）、Bergeron–Flajolet–Salvy（Y'=Φ(Y)）。

## 3b'. 2026-09-29 第二轮

- **文献风险已核实**：Medvedev–Mikhailov（ЖВМиМФ 2009, §6）的原文已在 mathnet.ru 读过。
  他们用的是 collision 形式，理想估计要在无穷树上定义，零方差需要条件 1−h/φ<1/n；
  文中还明确说，在他们之前的文献里没有研究过非线性情形的理想估计。
  我们用的是 absorption 形式，定理 B(f) 在无附加条件下成立。
  论文中已如实写明这一原理归属于他们。Mikhailov 1987/1992 的专著仍未核对。
- **新结果**：节点加权质量 E[N|H|]=W_N 同样与采样器无关，由此得到有界输出采样器的
  工作量下界。常数数据在接近 τ 时，输出为 O(W) 的采样器所需工作量是 Θ((τ−T)^{-1})，
  上下界匹配（推论 cor:work，数值已验证）。另外，二项式非线性下固定速率采样器能达到的
  时间比例有显式公式，随次数增大趋于 0。
- **附录已补全**：对应性证明（命题 prop:corr）、定理 D 的全部情形、定理 E 在 d≤4 的证明。
- **命题 F** 的二阶矩公式已用 sample_tree 独立验证（T=0.2、0.35 时 z 在 ±0.5 以内）。
- **决定**：不做 R^d 的数值例子，原因见 03 §2c。
- bib 中 HLT21、PP22、LMW98 三条已核对无误。
