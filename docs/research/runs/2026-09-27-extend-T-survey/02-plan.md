# 三个有边界的可行性计划

本轮到调研为止。下列是未来执行计划，尚未开始理论证明、Lean或算法实验。三条优先路线不是评分脚本确认的高价值shortlist；其意义是用低成本排除错误方向。D05 MLP作为已有能力对照，不计作原创突破。

## 统一的通过标准

固定反应系数、维度、终值族和时间单位；不靠缩小非线性系数伪装扩大T。分别记录T_rep（表示有效）、T_L2/总误差定理适用时间、T_use(ε,B)（精度与完整预算下可用时间）。不混淆PDE本身爆炸、树节点在有限时间无限增殖、权重不可积、方差无穷和有限但过大的工作量。

计划用ε=0.02作初步统一绝对RMSE目标，T网格0.25/0.5/1/2/4；这是可调整的实验设计，不是已有成功结果。先1维，通过后才考虑10维及以上。常数解用于精确代数检查；真正的能力比较还需非恒定terminal及界面附近的查询点。不同方法必须在同一组查询上比较，同时保留固定坐标与非饱和区域的误差，避免只看进入稳态的点。

成本同时记录CPU时间、终端/导数评估、总节点、峰值内存、reference/continuation训练或拟合成本、pilot成本；单次查询和多次查询摊销分开。记录所有失败和资源封顶，不能删除失败树后平均。先以每个小原型1–2 CPU小时作筛选上限；此处未启动这些计算。

对有偏方法，将近似/分裂/迭代/空间误差与采样误差分开；对无偏方法，先证明可积性和权重身份。重复实验的样本方差不能证明总体有限矩。比较统计误差时需独立重复或已证明的矩界，不能把未观察到重尾当作证书。

## P1：两段推进的 code 误差接口（D01）

目标命题：在选定且闭合的code范数中，中间终值扰动经过一段局部树传播，输出误差至多为局部采样误差加上可计算常数乘以接口误差；扰动后的终值仍保持下一段所需矩界。有限阶jet只在已证明有限code闭合时使用；否则明确解析/Gevrey权重和半径损失。不许把半线性现有定理直接说成任意高阶完全非线性定理。

理论路径：先把现有 [局部多项式/Picard分段](https://arxiv.org/pdf/1612.06790) 当作baseline，明确它的投影与近似误差；梯度对照用 [函数级face-lifting](https://arxiv.org/pdf/1710.10933)。从条件独立乘积的扰动界推导局部稳定常数，再写slab误差递推及累计成本。若中间code由内层MC提供，必须直接估计c(u)，不同因子独立；不能用c(无偏的u估计)代替。

Lean范围：有限乘积扰动不等式、有限slab误差递推、明确给定code包络下的代数充分条件。PDE正则性、随机树极限和拟合误差若未形式化，列成外部假设；不能靠新增axiom声称整个算法已经机器验证。

决定性数值检查：先两段T=0.8，用实际中间终值重新检查每段矩条件；这只超过某个原始共同率L2区间，不表示越过raw L1边界。oracle接口通过后，加入固定幅度ε cos(kx)扰动，检验高频导数影响和理论误差界。然后才推进T≥1.6、2、4，并允许所需多段。所有接口求值成本计入。

成功出口：在非恒定例中，两个slab的误差预算闭合；进一步在同精度预算下可用T明显增大。失败出口：接口code范数不闭合或成本相乘到不可用时，限定有限闭合子类或停止泛化。粗略工作量：理论1–3研究日、原型3–7日；不作为交付时限。

## P2：常数参考解下的阻尼残差表示（D03）

目标命题：明确改写后的随机量、证明其表示同一PDE，并给出至少一个非恒定终值邻域的更长矩证书。先用已知常数平衡v=1，不把未知真解当oracle参考。

理论路径：Allen–Cahn置w=u−1得w_t+Δw/2−2w−3w²−w³=0。候选普通单项式残差树吸收−2w后，其L1 majorant为y′=−2y+3y²+y³；非负阈值(√17−3)/2约0.56155。这只是待核验的构造入口，不能自动转给当前NPP code树，也不能从L1跳到L2或实用成本。对非恒定或不精确v，必须保留forcing R_v及全部所需导数。

现有 [HLTT killing-majorant](https://arxiv.org/pdf/1302.4624) 已给出此类稳定机制；[SCaSML](https://arxiv.org/html/2504.16172v3) 已用残差PDE和MLP纠正近似解。因此候选新意只在本项目的code对应、保留阻尼的矩与完整成本证书。

Lean范围：残差方程的多项式恒等式、阈值区间的代数不变条件、明确声明假设下的majorant比较模块。随机表示身份及无穷树极限另列实际证明状态。

决定性数值检查：先比较原raw树、残差但仍随机展开线性项、残差并吸收线性项三种机制；常数例核对公式，随后小幅非恒定扰动检验。再用跨越±1两相的波展示适用边界，不能将单相邻域胜利泛化到所有移动界面。检查T=2/4下L2和工作量，而不是只看均值。

成功出口：新随机表示在明确邻域具有更长的可证矩区间，并出现总成本收益。失败出口：只有L1改善但L2/成本失控时结合D01；一般参考解的code接口不闭合时保留常数参考。粗估：理论2–4日、原型1–3日；非恒定全code扩展可能数周。

## P3：bounded voting 的成本证书（D04）

目标命题：在一个明确定义的投票表示族内，证明可行率/次数及成本界，或证明已有majority在所选族内不能明显改进。后者同样能阻止无效实现。

理论路径：从不变区间归一化开始，检查Bernstein系数与投票概率。一般inward端点已有 [O’Dowd §4.4](https://www.stats.ox.ac.uk/~etheridg/odowd.pdf)；[AHR §§3.2–3.3](https://arxiv.org/pdf/2209.03435)给出相关表示。比较次数N、速率β、offspring混合与合法lazy投票。完整N叉树的节点成本含exp(β(N−1)T)，所以最低次数未必最便宜。单独最小化节点指数仍未保证最小方差×成本。

Lean范围：反应多项式与投票生成元对应、概率在[0,1]内、有限树输出有界、选定次数族的成本代数。lazy判定只有已数学确定输出时才可终止。

决定性数值检查：既有Allen–Cahn majority作baseline，加一种非Allen–Cahn但已知不变区间的多项式。先符号筛可行表示，若工作量指数已经劣于baseline则不跑长T；通过后才比较硬投票、软投票和精确提前判定在T=2/4的总误差/成本。目标至少2倍工作量改善只是预设接受目标，尚未观测到。

成功出口：相同精度下实际可用T或成本改善。失败出口：只能复现已知有界性则保留为baseline，不能称新突破。粗估：有限候选理论1–3日、原型2–5日；一般最优性定理更久。
