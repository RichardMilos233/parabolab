# 延长可用时间 T：本轮调研契约

日期：2026-09-27。模式：ideate（调研、比较、提出下一阶段计划）。
用户明确重新强调：总目标是延长时间 T，广泛找潜在方向。不能把“原论文已有小时间限制”或再次证明爆炸作为本轮主贡献；也不能未经选择直接进入一个较窄证明项目。

对象：现有 Nguwi–Penent–Privault coding-tree Monte Carlo，
u_t + (1/2)Δu + f(u,Du,...,D^n u)=0，terminal condition φ。
代码支持不同维度及若干高阶导数机制；现有短时间 lambda/q 优化已有较成熟证据。
保持本工作树的 branching/数学研究职责，NN 拟合工作仍属于 sibling；
相关 NN/BSDE/Picard 文献可以比较，不在本轮开发那条路线。

历史证据（本轮未重新运行）：2026-09-25 run 给出特定 raw-flat Allen–Cahn 的
L1 临界时间约1.44551，以及共同指数时钟的更小 L2 临界时间；
已知 bounded majority 比较表示已在非恒定例子数值检验到T=2，成本指数增长。
这些结果帮助排除不可能的 proposal-only 承诺，但不作为新的长T方案。

“延长 T”至少要分别报告：
1. 表示存在/可积的时间；
2. 有有限二阶矩或可证明总误差的时间；
3. 在同一误差目标 ε 和包含预计算、continuation、导数成本的预算 B 内可用的时间。
逐方法固定 PDE、时间单位、非线性系数、初值、维度和查询位置。
只缩小反应系数、改看饱和稳态点，或把T依赖常数藏起来，不算公平扩大能力。
允许有偏但有可控总误差的方法；单样本无偏不是默认硬约束。
本轮比较保留原树、改写表示、时间分段与替代随机迭代四类路线。
